# 红狐采集接入（2026-10-19）

用户已接受 T+1 更新与红狐积分消耗，热门内容来源改为每日热门作品榜，不再要求覆盖热点宝所有榜单。原三页布局保持不变。

## 操作与费用边界

- 游戏广场、热点广场只有点击“开始查询”才提交红狐请求。
- 切换游戏、榜单、行业、时间、回车、本地筛选、刷新状态和页面轮询均不提交收费搜索；原定时同步在红狐模式关闭。
- 游戏查询最多3页，每页最多50条，择取最多30条实际视频；不足时如实显示，不补造内容。按当前单价每次最多1.2积分。
- 热门榜每次只请求1次，当前单价0.6积分；取回结果后本地排序、筛选不计费。
- 在途请求去重；60秒内同条件成功结果复用原采集时间；失败或中断不自动重试。手动重试可能再次计费。
- 日期为北京时间完整自然日，昨日/截至昨日3天/截至昨日7天。T+1不等于实时更新，也不保证当天10点前昨日索引齐全。页面显示实际日期、采集时间和样本范围。

## 配置与凭据

后台设置 `CRAWL_GAME_SOURCE=redfox`、`CRAWL_HOTSPOT_SOURCE=redfox`，在入口填写红狐 API 密钥与腾讯文档目标链接。密钥只保存在本机忽略目录的私有文件（权限600），前端不回显；也兼容后台环境变量 `REDFOX_API_KEY`。

配置检查只验证已配置，不消耗搜索积分，不宣称密钥已通过真实接口认证。查询成功单独记录实际验证时间。腾讯链接读取成功与写入成功分开标注。

官方接口：游戏关键词 `/story/api/dy/data/searchWork`；每日热门作品 `/story/api/dy/search/likesRank`。未使用红狐 MCP。旧浏览器请求保留原provider，不能被转成付费红狐请求。

## 完整性与后续范围

- 返回结果保留来源作品ID、链接、公开指标、发布时间、采集时间、查询范围和回执。
- 图集与未知作品类型不伪装成视频；API有限返回不宣称抖音全网完整榜单。
- 游戏排序仅在实际取回样本内执行；课程更新仍待独立接入。
- 当前阶段只验收采集。学习任务后续应消费已手动采集的视频，并实读画面与音频；不得为了生成文档自动触发付费搜索。未经前两步验收，不进入文档生成或腾讯写入。

## 回滚

服务空闲后将两个 provider 配置恢复为 browser 并重启，即恢复原采集适配器。红狐来源记录与旧浏览器记录分别保存；不得删除或重写旧数据以制造验收结果。
