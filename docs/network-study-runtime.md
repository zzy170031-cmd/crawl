# 游戏学习任务入口（联网／本地）

此入口把用户选择来源的已有原片整理成游戏认知候选，与旧学习 worker 分开存储。率土真实原片、页面启动与展示、重启回读及独立语义审查已支持有限候选入口；它不认证完整游戏知识。配置执行器、单元测试通过或任务完成，不表示创作与腾讯交付已通过。

## 操作和边界

1. 游戏广场选择学习来源：联网来源手动查询目标游戏；本地来源上传自己的视频。红狐仍只在用户点击收费按钮并确认预算后调用；选择游戏、学习来源、刷新或轮询不调用收费搜索。
2. 联网学习只使用当前成功查询及已取得原片；本地学习只使用该游戏上传库，不要求红狐配置。跨日期的联网查询要求用户重新查询；不自动下载、补搜或回退到另一来源。上传保存本身不发送给宿主；用户启动学习后，代表图像与文本会由兼容宿主处理，不能宣传为纯离线。
3. 捕获完整来源库指纹，从最多30条候选中，按已有作者显示名称、时长区间和发布日期选最多8条可读原片；超过上限的数量另记。本地未知的作者、发布时间与互动不补造。显示名称不是账号身份认证，元数据选样不是相关性或优质内容判断。
4. 每片准备开头、中部和末尾三帧，归纳时绑定其中一张中部代表画面及完整自动语音转写。可另提供已核对指纹的公开发行方介绍、平台指南、图文和竞品表达资料。读取范围显式记录，不声称连续观看整片或全面纠正字幕。
5. 点击学习后，独立 FIFO 执行一次归纳，保存进度和结果。停止会取消本任务，刷新只读取；进程重启后未执行的任务需要显式继续。失败、已取消任务不因轮询重试。
6. 按游戏、选中来源及资料版本读取保存的档案。结果显示来源、事实/作者说法/创作建议和缺项；未知时长、互动或相关性不补零。没有播放量时不能生成曝光率或最优时长结论。

游戏学习服务于后续选题；重点原片拆解、游戏结合、完整方案和腾讯文档交付仍在创作任务阶段单独验收。联网与本地分别验收，不以某一游戏或来源通过代表另一来源的内容质量。

## 运行配置与接口

`CRAWL_STUDY_HOST_CLI` 必须指向已安装、兼容 `codex exec` 协议的可执行文件。它使用宿主现有账号和网络，**不是离线模式**；当前没有声明 Qwen、WorkBuddy 支持同一执行协议。此变量不解除服务端门禁。语音使用已有 `CRAWL_PYTHON`、`CRAWL_WHISPER_MODEL`，CPU/INT8，禁止自动下载。无需为这个候选再安装模型。

- `POST /api/game-study-tasks`：只接受 `{game, learning_source:"network"或"local"}`；固定服务器来源，不接受行、路径或命令。
- `GET /api/game-study-tasks`、`GET /api/game-study-tasks/:id`：只读任务，带 `task_store:"game-study"`；`resume_required` 表示需显式继续，不代表自动恢复。
- `POST /api/game-study-tasks/:id/cancel`：只停止同一独立存储中的任务，空对象请求。
- `GET /api/game-study-profile?game=...&learning_source=network或local`：只读同游戏、同来源档案；没有则返回空，不读旧本地档案。

状态保存在 `data/game-study-tasks/`，与旧任务库隔离。接口不返回原片路径、附件、宿主回执或审计路径。变更请求必须通过本机来源和会话令牌校验。停止、租约过期、来源变化和固定快照回读失败均不自动重试推理。

可选公开资料包放在 `data/study-public-references/<规范游戏名的SHA256>/pack.json`，格式为 `{version:"study-reference-pack-1",game,sources}`。附件只允许同目录安全文件名及 SHA256；读者拒绝路径穿越、符号链接和指纹变更，不接受用户上传目录作为公开资料。资料包不自动联网、也不因路径合法就认证发布者真实性。

不提交 `data/`、宿主审计、个人媒体、密钥或用户腾讯文档目标到远端仓库。
