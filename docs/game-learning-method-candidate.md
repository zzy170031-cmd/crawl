# 游戏学习方法调整（候选）

状态：2026-10-20 的方法与验收合同候选；保留现有 UI。尚未接入正式学习任务，不代表学习、创作或腾讯文档输出已经恢复。此前要求每条素材经过多阶段精细分析、继续下载更大模型的实验路线不再作为前置要求。

## 学习要解决的实际问题

让创作台在后续看见一个选题时，能够判断它与目标游戏有什么联系、可以采用什么表达形式、需要哪些游戏素材，以及哪里不能编。首次学习以 4–5 小时为预算，时间到仍有关键缺口就保留缺口，不用运行时长冒充完成。

| 学习面向 | 学什么 | 后续创作的用途 |
| --- | --- | --- |
| 游戏与玩家 | 背景、核心活动循环、玩家目标、入门与进阶处境；区分版本、赛季和活动 | 判断热点适合落到哪一种玩家处境，避免只换游戏名 |
| 常见玩法与语言 | 与内容生产有关的玩法、关键名词、黑话及适用条件；只核必要专名 | 写出玩家能理解的表达，避免剧情或错误转写变成游戏规则 |
| 内容类型 | 实际作品中的攻略、配置、战报、玩家故事、娱乐、更新资讯等；包括视频与图文 | 建立可选内容方向，而非预设所有游戏都有同一套类型 |
| 表达方法 | 谁在讲、解决什么问题、如何开头、证据怎样展示、信息如何组织、如何收尾 | 学会制作方法；学结构与功能，不照搬文案、画面和创意组合 |
| 时长、页数与互动 | 同游戏、同时间范围、同类型的赞评分享收藏及视频时长、图文页数 | 选择代表作品、描述样本表现；不推断曝光、平台权重、最佳时长或因果 |
| 平台质量要求 | 实际可访问的官方规则/课程及日期；转成原创增量、可读性、有效信息、事实范围等制作检查 | 将“优质”落实为可以检查的制作动作；不能给作品冒盖官方优质认证 |
| 同类游戏借鉴 | 2–3 款相近游戏的实际视频或图文，观察叙事、展示、信息组织的可迁移方式 | 扩充表达选择；不把竞品玩法、职业、数值或规则搬进目标游戏 |

## 采样与阅读

1. **候选池**：保留 20–30 条真实、去重、带来源日期与互动快照的作品。候选数不等于合格学习数；同一原片的搬运或重复上传不能补数量。
2. **基础筛选**：逐条快速看实际内容，确认与目标游戏的关系、主要类型及明显质量问题。标题、标签、封面只能帮助发现；无法判断的留待核。先看相关性和实质内容，再用互动数据挑代表，不按点赞一项包办质量判断。
3. **代表阅读**：通常选约 8–12 条，随实际类型覆盖调整。覆盖主要类型、不同作者和表达方式；可保留高互动但不适合学习的对照样本。每种主要类型尽量有多个案例，不能靠三个单例声称掌握整个游戏。
4. **按问题补读**：先了解整条主线与基本结构，再查看开头、信息转折、关键展示和结尾。静态表格不反复抽同一帧；看不懂的关键片段才增加画面/音频读取。图文确认实际页数、顺序及主要信息，只有封面不算整组阅读。
5. **深入拆解**：用户选择作品进入创作任务后，才按创作需要详细核对节奏、音画、关键原字、转场和游戏对照。不是任何作品都要求逐帧。

抽帧不能自动证明整片节奏、动态或音画同步；只有 ASR 也不能说明画面。每条观察保留实际读取范围。单个非关键疑词可以未知，不应使整份基础学习无法推进。

## 首次学习的时间安排

| 工作 | 预算 |
| --- | --- |
| 游戏背景、核心循环与必要术语 | 50 分钟 |
| 候选去重、相关性与质量初筛、分类型 | 40 分钟 |
| 代表视频与图文阅读、提炼表达方法 | 90 分钟 |
| 官方指导落实、互动与时长的分组观察 | 35 分钟 |
| 同类游戏实际表达案例 | 35 分钟 |
| 汇总档案与可用性检查 | 20 分钟 |
| 合计 | 270 分钟，约 4.5 小时 |

这是首个游戏的目标预算，不是强制等待时间或已测性能承诺。资料不可用、下载或人工验证等待单独记录；不靠无关样本填满预算。

## 输出与复用

每个游戏维护一份简明、可更新的游戏认知档案及来源索引：

- 游戏/版本与基本循环，常见玩家处境及必要术语。
- 实际观察到的内容类型，代表链接、适用人群和表达方法。
- 同类型的时长/页数与互动样本描述，明确样本量、日期和缺失值。
- 平台要求对应的制作动作与检查办法。
- 同类游戏可借鉴的方法、成立条件和禁止移植的机制。
- 后续创作需要准备的实机、配置、战报、人物或剧情素材。
- 已确认、来源陈述、观察、推测、创作设想和未知项分开记录。

后续查询增量更新已变化的作品、版本与规则，不重学所有旧视频。切换游戏读取各自档案，不串用游戏机制。刷新或学习不得暗中触发付费红狐查询；新检索由用户点击并接受对应预算。T+1 或历史结果标明日期，不宣称当天实时数据。

## 完成怎样判断

- 实际覆盖七个方面，并能解释代表作品在帮助哪类玩家、怎样组织信息、可借鉴什么、需要什么材料。列出七个栏目不等于完成。
- 主要类型的结论有实际内容支撑，互动比较在可比范围内；不足时明确不能得出的结论。不因缺播放量暂停所有学习。
- 用几种不同选题做匹配检查：指出具体游戏落点、表达方法、所需素材及不适合的原因。这是知识可用性验证，不提前写完整脚本或腾讯文档。
- 真实创作台入口能启动、取消、保存并回读档案；跨游戏隔离、来源绑定和费用边界得到验证，才恢复正式学习能力。
- 后续选定视频的重点分析、创作质量、腾讯写入与回读另行验收，学习通过不自动代表交付通过。

## 模型与当前实现边界

不再新增模型下载。现有视觉模型只为必要的实际画面读取服务，多语言 Whisper 按需要转写；静态资料、去重、统计与缓存由普通程序处理，归纳不能靠继续堆模型解决。

当前另有使用现有宿主助手账号的隔离候选，它依赖账号及网络，不是离线本地推理，也未证明所有助手工具均兼容。是否采用该入口必须与便携安装说明及实际创作台运行方式一起验收。现有本地模型保留不等于已经证明自动学习质量。
