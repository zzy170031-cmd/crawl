# 实施与维护计划

目标：助手和网页共享“学习游戏→浏览热点→确认选题→实际视频阅读→游戏结合→完整腾讯交付”。新仓库独立运行；旧工程和数据保持可回退。

1. 白名单迁移代码，组织SKILL、参考、配置、文档，排除个人运行数据。
2. 配置化路径和模型，允许空库启动，提供Mac浏览器启动与模型诊断。
3. 以SQLite事务/租约执行学习及创作任务；媒体批次检查点，证据和游戏版本绑定；接口支持状态、重试、取消。
4. 持久化榜单订阅，主动查询与历史筛选区分；一级行业仅用于来源支持的榜单。
5. 用媒体和互联网证据生成游戏资料及完整方案，消除标题模板正式交付路径。
6. 腾讯按任务/方案版本创建子表，正文、链接和样式分项验证；保留不明写入和人工冲突记录。
7. 进行受控测试、空库启动、浏览器检查、真实来源查询；在新M5进行真实模型与腾讯双入口验收。

提交阶段应清楚区分代码已实现与运行已验证。受控模型/MCP替身只验证执行器和异常分支，不能当真实创作质量证明。尚未取得M5会话时，保留具体操作清单和状态，不宣布全流程完成。
