此记录对应仓库同步，不等于完整业务发布。保持现有三页布局；每位使用者使用自己的红狐 API Key、腾讯 MCP 授权及目标表格。

## 本轮实测

- 在不含原设备 `.env`、数据库、模型、媒体、凭据的临时目录复制待发布源码，执行 `npm ci`：安装2个依赖包，审计0漏洞。
- 执行 `npm run setup`：只创建新配置和数据目录，下载模型0；配置实际加载为 Redfox/Redfox、后台执行器automatic、Qwen3-VL Instruct。automatic是消费用户已确认队列，不是自动收费搜索。
- `doctor --layer=collection` 正确报告“请配置自己的红狐API Key”，不借用开发者凭据、不发起收费验证。
- 在另一个本机端口启动，实际浏览连接页显示红狐Key、腾讯授权和表格链接入口；未配置时不能假称已连接。
- 启动与浏览后数据库查询任务0、业务任务0。未复制用户资料，未调用红狐付费接口或腾讯写入。
- setup重复执行与并发执行保留已有.env，Windows路径选择、分层doctor和错误脱敏有受控测试；Windows及各助手实际整链未验收。
- 独立检查发现并修正：新安装manual执行器配置导致Redfox请求绕回浏览器；默认CDP分支可能直接交付而没有草稿审阅。新增默认Redfox A/B与完成回执恢复测试，确认不会追加搜索或直接publish。
- 待同步源码检查排除了真实密钥、用户腾讯目标链接和设备个人路径；运行目录与模型、媒体、回执不提交。

- 完整受控回归：446/446通过；静态检查97个JS文件与Skill引用；XLSX合成场景2/2；Skill校验通过。真实业务仍按下方限制单独判断。

后续质量门禁修订：完整受控回归483项，460通过、0失败、23明确跳过。跳过项是当前固定门禁使其不可达的旧学习/交付流程，原断言保留，不计作通过；新的网页、worker、CLI及底层写入阻断与完成回执只读恢复均有执行测试。该结果证明当前暂停策略与程序分支，不证明模型语义质量或真实腾讯交付完成。

## 当前限制

追加质量止损：真实视频摘要发现方向反转与版本限定丢失，REV1同模型复核3/3漏检；REV2的3条仅因格式或证据无效被拦截，不能视为语义质量通过。因此本次源码更新固定保留实验质量门禁，暂停新批次学习、创作与腾讯写出，保留采集和旧证据查看。详见[真实初学记录](game-learning-acceptance-20261019.md)。

实际采集已按用户接受的 Redfox/T+1 范围验收。新的自动初学仍进行真实模型质量测试：抽帧/OCR、ASR、字幕点核、相关性判断和汇总均可能失败，必须保留缺口，不将凑数、模型安装或测试通过称为理解通过。完整选题深拆与腾讯双链回读尚未完成，不宣传“只填两个字段即可保证全部交付”。

公开发行方资料目前自动读取中国区App Store唯一同名游戏介绍；找不到或名称歧义保留未知。该介绍不是当前战法数值、具体配队或活动规则验证。视频初学与选题后的深入拆解分开，未读取的关键声音/动作仍需补证据。

## 回退与升级

更新前备份本机data与.env；执行git pull、npm ci后重启。不要用其他人的data或.env替换自己的资料。新初始化不会覆盖.env；旧配置需要按README核对来源、执行器与模型。代码回退使用所需已知提交，不删除data；若将来变更数据库结构，须另行给出迁移与回退说明。本版本新增学习检查点和版本资料，未清空既有任务。
