# 创作台布局约定

用户于2026-10-18确认三页排版。后续功能开发默认保持栏目顺序、导航、主色和标题位置，只有用户明确提出视觉修改时再调整。

- 左侧：游戏广场、热点广场、创作任务。
- 顶栏左侧仅显示各页标题：看懂游戏，找到灵感。/ 好选题，从这里发生。/ 输出新的创作方案。酒红色加粗24px；不显示“工作空间/页面名”。
- 游戏广场：目标游戏输入，素材/课堂标签，列表操作，视频内容。
- 热点广场：榜单/已选题标签，采集范围，筛选操作，实际内容。无当前游戏栏或重复返回按钮。
- 创作任务：方案表单、任务列表。无当前游戏栏、重复标题和返回按钮。
- 字体首选微软雅黑，操作14px、辅助13px、微标注最小12px；本机未发现微软雅黑字体文件，安装合法字体前回退苹方。不能把CSS首选声明当成字体已安装。
