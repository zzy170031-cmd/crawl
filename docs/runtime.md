# 配置与故障恢复

Apple M5 是目标验收设备，当前仓库未取得该设备运行证据。Ollama标准本机HTTP协议为默认适配；其他运行工具即使装了同名模型，也需额外协议适配。本版本不自动换成云服务或更小模型。

## 配置

根目录 `.env`：PORT、CRAWL_DATA_DIR、CRAWL_CDP_URL、CRAWL_MODEL_URL、HOTSPOT_VISION_MODEL、CRAWL_PYTHON、CRAWL_WHISPER_MODEL、CRAWL_WHISPER_CACHE、TENCENT_DOCS_TOKEN。可选 CRAWL_CHROME_PATH 指定Chrome。

数据路径相对于仓库根目录；Python可执行路径建议绝对路径。模型服务和CDP只允许本机地址；网页服务只监听127.0.0.1。应在装有模型的同一台 Mac 或 Windows 上运行整套应用。另一台设备安装模型不会让当前设备的 localhost 自动可用。Windows 安装步骤见 [Windows 安装与排错](install-windows.md)。

faster-whisper使用CPU int8，不假称通过Metal加速；视觉由Ollama处理，实际GPU后端和耗时需查看本机诊断及Ollama运行情况。ASR只读取现有缓存，目录/格式不匹配时明确失败。不要反复重装同名模型。

## 工作队列

SQLite事务存任务；工作者使用30秒租约并持续续租，失效任务可恢复。全局工作者锁限制模型并发为1，浏览器锁避免多个视频互相暂停。每个图像批次按媒体数据、模型digest及提示版本保存结果；中断不会丢失已成功批次。完整推理流必须done，截断/错误JSON不被接纳。单次模型调用180秒，明确429/503最多重试一次；其他失败直接报告，不无限循环。

取消会中止模型请求和媒体子进程；已发出的腾讯单次请求可能已生效，后续步骤停止并保留回执。重试先回读。人工编辑与未知部分写入不可安全区分时，停止覆盖，使用明确的新方案版本交付。

## 能力边界

- 浏览器捕获目前要求可播放、180秒内作品。画面每3秒左右抽样，长片最多约60帧；不是逐帧阅读。关键转折不足时任务进入待补读。
- 语音转写可能有游戏专名错字，音乐/音效未分析。核心依赖音效的作品不能自动交付；该限制不因M5算力而消失。
- 互联网游戏资料从可访问搜索结果正文提取，网页失败/权限不足不以模型记忆冒充资料。
- 腾讯完整正文回读与XLSX导出属性核验不同；导出下载域名/格式不支持时给出警告，不绕过权限。导出核验不是屏幕视觉验收。
- 自动订阅每轮预算10分钟，每组合下一小时重试，保留失败与跳过记录；不承诺全行业全榜每小时全量抓取。

模型质量不达标时保留真实失败记录，不通过放宽证据门槛换取“完成”。
