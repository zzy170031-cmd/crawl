# 配置、诊断与运行边界

本机 Node.js 24+ 服务、FFmpeg、Ollama 和 Python 转写进程共同运行。通过 Codex、Qwen Code 或 WorkBuddy 调用的是同一个后端；助手底座不替代视觉和语音模型。Windows 命令见 [安装说明](install-windows.md)，模型显式下载见 [README](../README.md#4-显式下载两个模型)。

## 配置层

| 项目 | 配置与含义 |
| --- | --- |
| 服务 | `PORT=4318`；只监听本机；从 `http://127.0.0.1:端口/` 打开，不双击 HTML |
| 数据 | `CRAWL_DATA_DIR`，相对仓库根目录；默认 `data/`，含数据库、凭据、私有回执及媒体 |
| 来源 | `CRAWL_GAME_SOURCE=redfox`、`CRAWL_HOTSPOT_SOURCE=redfox`；手动付费查询 |
| 红狐 | 本人 `REDFOX_API_KEY` 或网页本机保存；网页保存的 `data/redfox-credential.json` 优先 |
| 视觉 | `CRAWL_MODEL_URL=http://127.0.0.1:11434`；`HOTSPOT_VISION_MODEL=qwen3-vl:8b-instruct` |
| 语音 | `CRAWL_PYTHON`、`CRAWL_WHISPER_MODEL`；多语言 small、CPU/INT8；可选已有 `CRAWL_WHISPER_CACHE` |
| 腾讯 | 本人 `TENCENT_DOCS_TOKEN` 或网页保存凭据，环境变量优先；可选 `TENCENT_DOCS_TOKEN_FILE`；目标表格可在网页设置 |
| 备用浏览器模式 | 显式设置来源为 `browser` 时才需要 Chrome/CDP；不保证规避登录、验证码或平台限制 |

`node scripts/setup.mjs` 只创建缺失配置，填当前电脑路径，不搬运开发者配置、不自动安装。迁移目录后需检查绝对 Python/模型路径；跨机不能复用旧本机地址。模型服务/CDP 只接受 localhost 地址。环境变量修改后重启服务。

## 三层诊断

```sh
npm run doctor -- --layer=collection
npm run doctor -- --layer=analysis
npm run doctor -- --layer=delivery
# 默认检查所有层；可选双色图实际推理
npm run doctor -- --layer=analysis --probe
```

- **采集**：红狐仅检查本机密钥格式，不联网验证、不扣积分；此模式不检查 Chrome/CDP。
- **分析**：检查 ffmpeg/ffprobe、Ollama 是否有配置模型、能否离线加载多语言 Whisper（CPU/INT8）。不下载模型；默认不推理。
- **交付**：检查本机腾讯凭据是否存在且格式可用；不进行腾讯请求，不检查远程权限或写入。目标表格及远程连接须在创作台另行确认。

报告保存 `data/doctor.json`，错误不打印原始密钥、原始异常响应。一个层未就绪不等于其他层不可用；安装诊断通过也不等于完整业务验收。

## 查询、原片和学习是不同步骤

查询必须手动发起。T+1 范围为北京时间截至昨天的 1/3/7 个完整自然日；记录 API 请求范围、实际发布日期、采集时间与分页限制。切换条件只切换本地展示，不自动扣费。新安装的 CRAWL_SEARCH_MODE=automatic 指后台自动执行用户已确认的查询队列，不是定时或切换条件自动收费。部分样本、合法空结果和失败不同；已采集数据不能冒充实时全库。

原片获取先报价再确认：预算、选中作品和查询回执绑定，恢复优先复用已保存解析回执和已验证文件。报价确认有效期 15 分钟；首次开始后执行期限为最多 30 条、每条 6 分钟且不少于 15 分钟；重复开始不延长期限或增加预算。期限限制发起新的解析请求；已在执行的下载可能稍后结束。未知收费结果不自动再次解析。下载/重定向必须通过安全域名检查；拒绝的资源明确失败，不替换成占位内容。

原片以 ID、公开元数据、音视频时长和 SHA-256 绑定；派生帧和音轨也核验身份与摘要。准备帧和音轨只是采集成功，不代表已经理解。学习使用当前成功查询快照；旧任务检查点须明确标为复用并保留原读取时间，不能伪装成本次新分析。至少 20 条候选/媒体的数量条件不证明内容质量或语义多样性。

模型阅读是抽帧与带时间戳的语音结合，不是逐帧全片理解；人名和游戏术语需核对字幕，音乐/音效理解仍有限制。模型超时、截断、证据不够或不确定时报告失败/待补读，不能改用标题猜测。

## 腾讯交付和数据管理

客户端独立调用 `https://docs.qq.com/openapi/mcp`；所用 Token 由本机用户提供，既不依赖 Codex 的私有连接器，也不继承其他助手的授权。目标在线表格链接不代表可编辑，连接确认不代表方案已写入。方案内容、目标子表与写入范围确认后才能交付，最终须保留写入/回读证据。

取消可中止后续步骤，但已经发出的远程请求可能已生效；恢复时先核验回执，避免重复付费或重复写入。不能明确辨别人工编辑与未知部分写入时，停止覆盖并使用明确的新版本。

运行目录、Token、模型、原片、来源回执与用户表格均不入 Git；只共享代码与脱敏说明。当前采集阶段真实验收不包括模型质量、语义独立性和两条腾讯交付链路，详见 [采集审计](collection-goal-audit-20261019.md)。
