# 专用后台来源采集器

`app/automatic-collector.mjs` 创建独立持久 Chrome profile（默认 `data/collector-profile`）。仅正常 Playwright `launchPersistentContext`、站点可见 DOM 与页面操作；被动读取本轮页面正常产生的公开榜单响应，不重放或额外请求来源接口。没有 CDP、普通浏览器/IAB profile 复用、cookie 导出、请求拦截修改、反检测参数或验证码绕过。profile 和会话只保存在已有 gitignored `data/` 中。外部运行时必须串行调用并管理持久任务租约。

## 接口

- `createAutomaticCollector({ profileDir, executablePath?, channel?, timeoutMs?, chromium? })`：同步创建，浏览器懒启动；`chromium` 仅依赖注入测试。
- `collect(payload, {signal})`：返回 SideBridge 搜索结果协议。未人工确认前使用独立 headless；显式确认原生登录后继续使用同一个原生 context。正常采集使用临时工作页，不调用 bringToFront，不自动打开新的登录窗口。原生窗口可保持最小化，但是否抢焦点仍需真机验证。
- `probe(site, {signal})`：单站实际页面预检，返回 `site/state/checked_at/message`。state 为 ready、login_required、verification_required、failed；不是检查 profile 目录是否存在。
- `login(site, {signal})`：显式用户动作打开真实浏览器登录窗口，沿用采集专用会话；site 只接受 douyin 或 douhot。不会在其他浏览器的登录态上操作。
- `verifyLogin(site,{signal})`：核验当前登录页实际账号及验证状态，证明绑定当前 context、世代、站点和页面。
- `resume({signal})`：当前原生证明成立时保留同一 context 与各站登录页，转入采集模式；没有证明时不会保留未验证会话。调用方仍需 probe；账号确认不代表搜索或榜单已解锁。
- 默认原生登录拒绝 `loginView()` / `loginInput()`，旧截图子页仅提供返回创作台的入口。用户直接在真实浏览器完成扫码、点击与验证。
- `CRAWL_HEADLESS_EXECUTABLE` 指定独立后台浏览器；缺失时明确失败，不回退到日常 Chrome。原生登录与独立 headless 共用专用 profile，但绝不同时启动两个 context。已验证原生 context 优先复用，避免确认后切换浏览器环境。
- 腾讯文档复用已有授权，界面只填写目标在线表格链接。后台通过官方返回的 URL/ID 映射核对；无法找到新链接时提示先打开文档再保存，不修改旧目标。仅在授权缺失或失效时显示重新授权入口。
- `status()`：非敏感工作状态，不含 Cookie、Token、storageState。
- `close()`：关闭上下文，中止导航；后续 collect 可重新建立。

错误 `LOGIN_REQUIRED`、`VERIFICATION_REQUIRED`、`SOURCE_FAILED` 分开。403/安全验证立即停止，不伪装成空结果。没有识别到结果也没有明确空态时失败。`cancelOperation()` 在有已验证原生会话时只清理当前操作创建的工作页与弹窗，保留各站登录页；没有已验证原生会话才关闭上下文。清理失败或超时阻止后续采集，迟到结果不能保存。显式停止服务仍关闭全部专用上下文；真实 context 关闭立即撤销两个来源的就绪证明，重启后须重新检查。

## 实际来源与范围

游戏：真实 `/search/<keyword>?type=video`，读取可见 `<a>` 的具体视频链接、标题、作者、可见点赞指标，最多12次滚动/30个不同视频。无视频ID、无标题作者、图文 `/note/` 均不冒充视频。实际默认排序/时间范围写入 scope；尚未验证来源筛选菜单，**不会把请求的近7天和最多点赞宣称为已经应用**。返回30候选也不证明20条有效音画学习或内容质量。

热点宝：请求实际页面 board/time/category。一级行业按来源当时可见子类勾选，子行业精确勾选；不将静态目录中过时的子类写入请求。确认 URL、可见时间/榜单/行业和页码。结构化数据只接受同一页面请求轮次、精确 scope/page 的正常响应；真实空标题/作者原样保存，展示中使用缺失提示。保留精确字符串视频ID、来源原始指标及显式null，不把数组位置当官方排名，不将舍入展示数当原始值。

分页候选按页面实际“下一页”逐页读取，点击至少间隔2秒，不刷新页面或重试失败页。每页独立请求轮次；同页迟到冲突、范围/页码变化、跨页重复ID或元数据变化均不能混入结果。终页必须在同一最终 DOM 快照中确认页码、scope和下一页已禁用。每榜最多50页/1500条；触及上限但仍有下一页即失败，不冒充完成。成功记录 pagination 的实际页数、条数和标称total差额，区分“全部可访问分页已读”与“官方标称总数全部取得”；短响应不代表末页。整榜中途失败不提交半榜覆盖旧快照，诊断保留已读进度。

完整分页运行预算默认10分钟（`CRAWL_COLLECTOR_TIMEOUT_MS`，最大600000毫秒），单次导航与响应仍各有较短超时。界面状态轮询只读本地，不反复访问来源。实际分页验收状态以 `docs/automatic-collection-acceptance.md` 的现场记录为准；候选代码与受控测试不构成实测通过。

目前视频榜1001–1005有实现。**话题/搜索榜2001/2002/3001/3002尚未验证DOM契约，明确失败；全部榜单请求允许部分视频榜成功，并列出失败范围。** 历史首屏采集不是完整榜单；新分页候选需另行真实验收。源页面选择器与登录检测必须真机验收；受控单元测试不证明已登录或采集端到端通过。

未引入封面远程抓取：采集不向任意图片主机发起请求，现有媒体缓存流程独立处理。源数据中的文本只作为数据，不作为执行指令。

## 减少重复来源访问

- 页面每5秒的状态轮询仅读取本机接口，不再由每个客户端分别触发来源连接复检；自动复检由服务器统一管理。
- 对当前站具有有效原生证明的连接复检，在同一受保护页面重新检查验证提示与本人账号。不会新开首页；证明过期、上下文/页面变化或来源挑战不能用缓存冒充成功。
- 自动广场搜索在60秒内复用完全相同范围的已完成公开请求，沿用请求ID及来源时间，明确提示复用。不同关键词、时间、榜单、行业、排序和任务身份不得交叉复用。
- 后台两次采集之间至少间隔15秒；间隔持久化，并在取得队列锁后复核。等待期间请求保持pending。相同创建毫秒按插入顺序处理。
- 以上限制降低重复访问，不能保证消除平台风控；验证码仍停止队列，真实来源验收不得以受控测试替代。
