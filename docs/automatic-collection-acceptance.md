# 自动采集验收（实施中）

用户目标：现有 UI 保持；独立网页切换游戏、行业、时间后，后台自动取得真实来源数据，不依赖聊天助手回填。正常采集不弹出浏览器，登录或验证才交还用户。

## 合同

- 采用独立本机采集会话；不复制右侧或用户普通浏览器的 Cookie、令牌和登录目录。
- 搜索队列由服务进程持续消费；网页关闭、聊天不操作不影响已经提交的任务。
- 采集范围、时间、具体作品链接、来源指标随快照保存；真实空结果必须有范围核验，失败不能伪装成空结果。
- 登录、验证码、超时、来源页面变化均为明确状态；不绕过验证，不无上限重试或反复弹窗。
- 原素材、学习证据、腾讯交付历史保留；自动搜索不等于原片核验、游戏资料完成或创作交付。
- 仅允许抖音搜索与热点宝读取，不发送消息、不发布视频、不修改账号或腾讯内容。

## 完成判据

1. 从未采集过的游戏：网页提交后不调用 bridge fulfill，后台产生实际记录和来源封面。
2. 同游戏切换与不同游戏切换：结果严格属于当前游戏，旧请求晚到不能覆盖当前列表。
3. 至少两个行业 × 两个时间窗口：源页面实际条件与快照/页面一致。
4. 两个独立网页客户端：读取同一后台任务与快照；刷新不丢任务、不重复采集。
5. 重启：任务可恢复；租约失效不允许两个执行器同时写同一次结果。
6. 登录失效、验证码、来源错误与真实空榜分别测试；失败显示原因并可恢复。
7. 正常后台无可见新标签；仅登录操作打开专用会话；临时详情页及时关闭。
8. 受控测试与真实网站验收分开记录，独立复核后才判定通过。

## 信任边界与恢复

本机服务仅监听回环地址；写接口保留来源和会话令牌检查。网页材料不作为指令。浏览器文件仅置于被 Git 忽略的数据目录，日志不输出凭证。采集器只能使用允许的站点、有限页数与超时。回退方式是关闭自动搜索配置，恢复助手模式；不删除数据库、快照或登录资料。
