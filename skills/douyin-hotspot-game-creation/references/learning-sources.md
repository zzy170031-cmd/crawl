## 每个游戏如何找资料

优先游戏发行方官网、官方帮助、版本/赛季公告；补充有来源和日期的专业玩家资料，再与已读原片交叉核对。记录title/url/publisher/published_at/read_at/game_version/read_boundary/supported_claims/conflicts。只发现链接没有读正文时标discovered；成功读正文才可支持具体事实。官方页面没有覆盖的机制保持未知。

不将GitHub社区Skill当具体游戏官方资料，不将广告创意规则或其他平台规范泛化到所有抖音内容。资料过期、版本冲突时保留旧事实适用期，更新新版本，已有任务继续绑定原认知版本。
