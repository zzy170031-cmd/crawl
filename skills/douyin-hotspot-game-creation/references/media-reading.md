# 视频阅读与证据

阅读深度按阶段区分：前置学习从实际音画取得简短内容认知和关键术语，标记覆盖与未知；选题后的创作任务再完成下述详细时间轴、结构作用和游戏迁移。两阶段复用同一原片证据，不能把前置抽样宣称完整观看；不要求对整个学习池逐条写完整策划。

先确认具体作品ID、作者、标题、落地URL、时长；补充文件必须与同一版本对应。定点画面覆盖开头、中间和结尾，关键转折、快切字幕、对白回应处需要加密核对。静态帧不能证明运动轨迹、精确剪辑点或画外音。

对白按语义轮次理解：谁说什么、对谁回应、关系或信息如何变化、动作结果如何承接。自动转写的专名、同音词、说话人不可直接当已核对事实。没有识别到语音不等于没有声音。

分别记录画面、字幕、语音、音乐、音效的读取状态。声音触发笑点、冲突或关键揭示时，必须具备实际声音证据。当前Qwen抽帧+Whisper路径没有音乐音效理解，核心依赖声音的任务进入待补读；可在后续加入经验证的声音适配器，不拿文字描述冒充听音。

每条观察绑定时间位置；推断另列并引用证据。不把所有作品都套钩子/反转。方法迁移使用“原片证据→表达作用→目标游戏行动/玩家关系→游戏依据/失效条件”。美术类比、玩家情绪、生活情景可作为间接方向，但不得伪称游戏玩法。

当前自动捕获仅处理不超过180秒的可播放视频；更长或无法播放的作品明确报错。没有当前读取证据时，不生成完整拆解结论。缓存按媒体、模型和提示版本校验，不能复用无身份的旧输出。
