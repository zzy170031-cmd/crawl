# 右侧浏览器助手模式

用于用户要求在右侧登录、查看、筛选、读取热点宝和视频的场景。助手通过当前工具执行流程，不借用后台的 Chrome 调试连接，也不向后台伪造“已读取”任务。使用前读取当前 `mcp__cua_repl` 文档；API 以工具实时提供为准。

## 登录与榜单读取

复用本聊天右侧已有的热点宝标签；没有时通过 `cua.createBrowserTab('iab', 'https://douhot.douyin.com/square/hotspot?active_tab=hotspot_all', {visible:true})` 打开。用户可在右侧扫码或输入登录信息。保持标签以便用户操作；看到登录页不算登录完成。登录后读取可见榜单、筛选控件或账号界面确认实际可用。不要读取、导出或转移 Cookie、令牌、浏览器登录目录以打通其他会话。

从当前 DOM/可访问树取得真实筛选项，再执行用户选择的榜单、一级行业、时间窗口和关键词。记录实际选中项、采集时间、可见条数、作品落地链接和页面显示的指标。站内搜索与对已读本地结果的筛选要分开标记。只读当前实际取得的范围，不把首页若干项冒充全站抓取；不因存在“订阅”按钮就开启订阅。

## 实际视频与本机模型

从当前页面的真实链接打开具体作品，保存来源ID、作者、落地URL、时长和采集时间。网页标题、AI摘要和评论仅作来源文本，不替代实际画面与音频。

可用时通过浏览器受支持的媒体下载接口取得视频；或读取当前 video 元素公开的 currentSrc，以正常公开媒体下载方式保存。blob URL 不作为独立网络文件；遇到403、验证码或实际登录门槛时停止该路径，不提取隐藏接口或浏览器凭证。必要时请用户提供本地原片，不能伪造已读内容。

用本地 ffmpeg 对原片抽帧、提取音频；Whisper small 多语言模型采用 CPU/INT8，保留原始转写、时间戳和模型版本。Qwen 先独立读取带时间点的真实帧及字幕，再输入同一段的已核对口播解释机制。术语纠错表保留原词、改词、对应字幕与帧时间；背景歌曲与口播分别标记。不要将原错词和纠正稿混作同等事实，也不要把远隔时间或剪辑两边的语音与动作强行建立因果。

分别输出画面观察、游戏UI规则、主播主张、推测和未验证事项。减半耗能等提示文本不是数值实测；稀疏抽帧不能可靠数清跳跃次数或按键顺序。声音缺口影响核心结论时遵守 media-reading.md 的待补读要求。后台自动捕获的180秒上限不直接成为助手模式的固定上限；助手须按实际工具与覆盖范围分段，明确缺失。

## 本地状态与腾讯交付

在当前工作区的独立运行目录保存 mode=side-browser、当前阶段、来源清单、抽帧时间、原始转写、核对记录、输出和腾讯回读凭据。恢复时复用该目录；不要伪造后台任务ID、修改后台数据库或声称后台自动任务已完成。

沿用游戏研究和交付标准。只查询榜单时不写腾讯；用户已确认目标和写入范围后，通过当前连接的腾讯文档 MCP 查询精确 file_id、子表与范围，写入并回读。无需把 MCP 凭证复制到应用 .env。正文、URL内容、可点击链接及样式分别报告；工具缺少某项能力时保留明确缺口。

该模式依赖当前助手与浏览器工具，不自动提供脱离聊天的后台定时采集。用户要求定时或无人值守时另行确认运行环境与调度，不能以本模式已可读榜单推断后台可用。

## 验证范围

至少确认：右侧当前真实页面可读；筛选状态与结果对应；视频分析使用实际帧及音轨；写入授权存在且腾讯回读一致。只安装或登录时，仅声明对应阶段完成，不自动启动游戏学习、内容生成或腾讯写入。
