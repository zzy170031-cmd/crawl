# 完整策划与腾讯交付

A模式保留原片读取范围、时间轴、结构作用、迁移条件及新的完整方案。B模式先说明事件/话题实际意义，结合代表视频说明观众关注点，再给游戏方向。默认视频；明确图文时独立设计首图、逐页主视觉/文案、推进和末页兑现。

每个方向给具体题目、切口、开头、完整原创台词或文案、分镜/页序、素材、声音/剪辑建议及结尾。不能用“发生冲突”“揭晓原因”等空任务代替关键对白。无对白作品不强加人物对话。

低中高按真实投入和观看收益划分：低档已有素材即可独立表达；中档增加定向录制、比较或第二视角；高档可增加研究、实测或多人叙事。稀有资产/人员/素材未确认时写清前提，不宣称立即可拍。不保证流量和未经实测工时。

写入前确定腾讯在线表格file_id、URL及任务范围；配置和令牌不入仓库。每任务/方案版本使用独立子表并保存ID，已有用户内容不覆盖。发生不明部分写入时先回读，不盲目重写空白；无法区别人工清空时停下请用户核对。

原片、游戏参考作品、互联网资料分列。搜索入口不是原片，不静默删掉长文或多条引用。正文微软雅黑、换行顶端对齐，低中高用浅绿/蓝/橙并保留文字；不擅改既有冻结状态。

正文、URL内容、可点击超链接、样式分别验收。腾讯适配器先逐格回读正文，再通过MCP导出XLSX检查链接与字体、换行、分档颜色；导出或属性验证失败时保留分项警告。导出检查不是屏幕视觉验收，当前仍需真实账户跑通。完成提示必须保留这些差异。
