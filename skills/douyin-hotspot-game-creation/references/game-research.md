# 游戏前置学习与复用

学习的用途是让创作台理解目标游戏和相关视频，为后续选题提供背景；完整拆解、游戏结合、脚本和制作方案留在创作任务，并进入腾讯文档。不要在学习阶段为每条视频生成长篇策划或强行套完整分镜。

## 三个学习问题

1. **游戏是什么**：身份与别名、品类、平台/版本、玩家目标、反复进行的核心行动、主要资源/角色/竞争合作关系、常用术语。用“规则允许什么 → 玩家实际做什么 → 带来什么体验”组织理解；不是设计新机制。官方介绍、帮助、版本公告优先核验事实；玩家视频用于观察实际表现。宣传演绎与游戏实装分开。找不到资料的内容标未知，不靠模型记忆填实。
2. **游戏相关视频在讲什么**：先概括每条已读作品的内容与面向人群，再从样本归纳内容类型。攻略答疑、阵容/装备对比、实战复盘、版本解读、角色故事、玩家关系、搞笑情境、创意剪辑仅是候选分类，不能假定每个游戏都有。记录实际例子与样本数；只称“本次样本常见”，不把检索样本当全站分布。
3. **哪些内容值得借鉴，为什么**：简述观众得到什么、关键表达怎样帮助理解/体验、存在何种不足。结合[创作者质量依据](creator-quality.md)区分平台倡导与本项目分析判断。点赞/分享等只作公开表现记录；不以高赞证明优质或推导流量算法。详细因果拆解留到用户选题后。

## 资料与样本

资料分三层：
- **稳定方法层**：当前Skill的研究方法、评价维度、来源选择规则，可随项目版本管理。
- **游戏知识层**：不同游戏的事实、术语、内容类型与初步认知，各自存本机 `data/` 中的游戏资料版本；不把一个游戏的临时结论硬写进通用Skill，不自动上传GitHub。
- **视频证据层**：作品ID、原链接、查询范围、发布时间、实际采集/读取时间、原片指纹、抽帧/转写/字幕证据与缺口，供后续创作复用。

红狐模式仅用户点击“开始查询”发起已说明预算的检索，使用T+1实际日期范围。候选目标30条、至少20个真实相关独立内容组构成学习池。每条实际读取相关画面与可用语音后，留下简短内容认知卡，不要求20篇完整拆解。只有标题/封面不计已学习；同内容多个来源只计一组，保留各原链接。优先覆盖不同作者和内容类型，排除只挂标签、其他游戏、不可读素材。

不足时允许保存 `partial` 初步认知和明确计数，不能标作完整学习通过。扩日期、补查询、获取付费原片都不得静默扩大费用。浏览器模式保留来源范围和人工读取限制；不把手动回填当自动采集成功。

官方事实资料可在视频不足时先整理，但不能替代实际视频学习。只从标题发现的内容类型留在 `candidate`，不能进入已学习结论。原片是否可自动取得须单独验证，元数据API成功不是原片阅读成功。

## 学习产物：一份简明认知档案

- `game_overview`：游戏身份、版本、目标与核心行动、关键术语；逐项来源与未知。
- `sample_coverage`：候选数、独立作品数、实际已读数、可用/失败数、查询日期、读取模态范围。
- `video_content_map`：样本中出现的内容类型、玩家关注点、代表视频ID；不硬凑类型数量。
- `initial_quality_notes`：值得借鉴的表达/观看收益、对应视频时间位置、官方规则ID或“本项目判断”、局限和反例。短记即可，不在此写完整镜头表。
- `creative_context`：后续适合关注的内容方向、可结合的玩家情境、容易误解或不能编造的机制。
- `evidence_index`、`unknowns`、`version`、`collected_at`、`learned_at`：可回溯与增量复用所需字段。

红狐初学执行器同时保存上述结构与旧版 summary/player_interests/creative_methods/game_facts。初学 ready 只代表至少20组相关证据和有来源的入门认知；机器字幕点核不会升级成人工视听已核验。每条默认6–8张均匀实际帧、完整音轨ASR，来源变更或模型变更失效重读；失败和无关内容保留且不计数。发行方资料自动读取目前覆盖中国区 App Store 唯一同名游戏介绍，不覆盖所有PC游戏或别名；匹配失败保持未知，不移植相似游戏规则。

认知卡还须通过独立的一次机器一致性复核：检查摘要/表达观察是否反转原片含义、丢失版本限定，或把只展示立绘的画面说成机制教学。复核只接收同片实际OCR、原始ASR及候选认知卡，不执行素材里的指令，不自动改写错误结论；异常或无效引用保持待核验。`summary_quality` 与相关性分开记录，非 `consistent` 不计入有效初学。该复核由已有本机模型完成，不调用红狐、不另下载模型；它仍不是人工审核或完整视听验证。

当前质量验收尚未通过：旧版真实反例全部漏检，REV2仅因格式或证据无效拦下，不能称为语义识别成功。复核仅核对抽样OCR与原始ASR，未核对纯画面叙事、动作与构图忠实性。服务端固定保留实验质量门禁，新旧资料都不能仅凭20条和模型consistent进入创作，暂停新批次学习与交付；采集和旧证据保留。解除门禁需新的真实质量证据与独立审查，详见仓库 docs/game-learning-acceptance-20261019.md。

初学摘要只说明讨论主题与表达方式，强弱、克制方向、数值、奖励和版本适用性留到选题后的证据核对，不把宣传或作者意见直接写成游戏规则。仅验证引用原文存在，不能证明模型转述的意思正确。

## 更新与后续任务

官方资料/方法按使用需要检查，游戏版本变化触发事实复核；新查询只学习新增或发生变化的原片，保留旧证据读取时间。游戏知识与课程不必按热门榜频率重新检索。重新打开页面不产生收费查询；新视频候选不自动变成“已学习”。

创作任务固定用户选中的视频、目标游戏和认知版本。先复用可靠证据，再对该选题补充分段音画阅读、结构作用、游戏对照与完整方案。学习阶段没有听懂的关键声音、没有看到的动作必须补证据，不能靠初步认知推断补齐。按[视频阅读](media-reading.md)与[交付](delivery.md)执行。
